### 功能二：定时催水 + 周报

说「每两小时催我」，它先问窗口，再建定时提醒：

```
0 9-21/2 * * *  →  9、11、13、15、17、19、21 点各一次
```

夜里不打扰；说「停掉提醒」就真删。

说「周报」，出最近 7 天：饮水次数、总量、日均、达标天数、最佳单日、任务打卡、拒绝次数，还有一条**本周期最佳借口**。

```
└─ assets/poster-demo.png   通告卡示例
```

常用命令：

```powershell
# 在 skill 目录下运行；或把 $D 换成脚本的绝对路径
$D = "scripts\dashui.py"
py -3.12 $D daily
py -3.12 $D checkin
py -3.12 $D report --days 7
py -3.12 $D style --set instructor
py -3.12 $D poster --out "output\dashui-card.html"
```

依赖：Python 3.12，无第三方库。状态写到 `%USERPROFILE%\.dashui\state.json`，可用 `DASHUI_HOME` 改。
